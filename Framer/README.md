# CampusBite – Framer Website

CampusBite is a college food ordering website designed to make campus food ordering simple and convenient.

## Website Features
- Food menu and categories
- Popular food items
- Special offers
- Food ordering information
- Campus-focused design
- Navigation between website sections

## Design
- Purple: #6C3BFF
- Coral: #FF6B4A
- Yellow: #FFC857
- Teal: #20BFA9
- Cream: #FFF9F2

**Tagline:** Order Fast. Eat Fresh.
