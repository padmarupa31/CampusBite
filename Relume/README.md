# CampusBite – Relume Design

Relume was used to plan the CampusBite website structure and page layouts.

## Deliverables
- Website Sitemap
- Website Wireframes

## Planned Pages
1. Home
2. Menu
3. Offers
4. Food Details
5. Order Tracking
6. About
7. Contact
8. Cart
9. Checkout

## Purpose
The sitemap defines the website hierarchy, while the wireframes plan the layout of each page.
