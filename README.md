# 🍔CampusBite | College Food Ordering App

A UI/UX design project focused on making campus food ordering simple, convenient, and user-friendly.

**Tagline:** Order Fast. Eat Fresh.

## Project Overview

CampusBite is a college food ordering platform concept that helps students explore food options, discover offers, view menu items, and navigate an organised ordering experience.

This project demonstrates the design process from brand identity creation to website planning and interface design.

## Brand Identity

CampusBite uses a colourful, modern visual identity inspired by campus life and food ordering.

**Colour Palette**

- Purple — `#6C3BFF`
- Coral Orange — `#FF6B4A`
- Sunny Yellow — `#FFC857`
- Fresh Teal — `#20BFA9`
- Soft Cream — `#FFF9F2`

**Typography**
- Poppins for headings and buttons
- Inter for body text and navigation

## Design Workflow

**Pomelli → Relume Sitemap → Relume Wireframes → Framer → Testing**

The workflow connects brand development, information architecture, page layout planning, and website design in a single UI/UX project.

## Project Outcome

CampusBite brings together a consistent brand identity, a structured website plan, and a published website concept designed around the needs of college students.
